## 修复：视角跳转无效 + 单位实时状态面板空白

### 问题 1：空战中「🔴红方位置 / 🔵蓝方位置」视角没有变化
根因（`pro/client/js/View3D.js` 原有实现）：

```js
const offset = subVectors(camera.position, newTarget);
camera.position.copy(newTarget).add(offset);   // == 原 camera.position，相机原地不动
```
只用 offset = 相机位置 - 新目标点，再把它加回新目标点 → 数学恒等，相机**从未移动**，仅 lookAt 转了一点点视角。

修复要点：
- `focusOnPosition(x, y, z, dist)`：改为「目标点 + 固定斜后上方机位（dir=(0.6,0.75,0.9) 归一化 × dist）」，支持高度 z 与距离参数。
- `main.js focusOnSide()` 重写：按阵营单位计算中心点与散布，2D 用 `flyTo/flyToBounds`（单单位拉近到 ≥14 级），3D 用新的 focusOnPosition。
- 新增持续跟随：`app.followSide` + `View3D.setFollowSide(side)` / `updateFollowCamera()`（单机也跟随，距离自适应），再次点同一按钮取消跟随；与「🎥双机跟随」互斥（AirDuel.toggleFollow 会调 `app.clearFollowSide()`）。
- 2D 地图每次状态/回放帧 `updateFollowView()` → `map.panTo(..., {animate:false})` 跟随。

### 问题 2：单位实时状态空白、无法切换红蓝方
右侧「📋单位实时状态」原来只有点击地图单位才会填内容，空战中小图标高速运动很难点中。
- `index.html`：新增红/蓝方切换按钮（`#btnStatusRed/#btnStatusBlue`）、单位下拉 `#unitSelect`、◀上一个 / 下一个▶ / 🎯定位。
- `main.js`：新增 `viewEntities/unitsOfSide/sideExtent/getDuelParty/initUnitStatusControls/setStatusSide/selectUnitById/cycleUnit/focusOnEntity/refreshUnitPicker/unitLabel/resetUnitStatusPanel`。
  - 每帧刷新下拉（成员变化才重建 DOM），无选中时自动选中该阵营第一个存活单位 → 面板永不空白。
  - 推演与回放共用同一套逻辑（`updateState` 与 `syncPanelsForReplay` 都调 `refreshUnitPicker`）；`replayActive` 标记决定 `viewEntities()` 取 state 还是当前回放帧。
  - `showEntityInfo(entity, party)`：新增「✈️空战状态」块（机动/空空弹/干扰弹/俯仰滚转/被锁定告警，数据来自 `duel.parties`）；maxHp 兜底，标题底色按阵营区分。
  - `Map2D.highlightEntity(id, openPopup=true)`：静默自动选中不弹地图浮窗。
